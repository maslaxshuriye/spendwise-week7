## 1. Project Overview

SpendWise is a modern, responsive personal budget and expense tracking application. It helps users manage their money, record daily expenses, monitor spending, and track their remaining budget.

The application provides a professional dashboard with simple tools for managing personal finances.

## 2. Project Objectives

- Build a professional financial dashboard.
- Allow users to set and update their budgets.
- Record and manage daily expenses.
- Calculate total expenses automatically.
- Display the remaining budget.
- Save financial information using browser Local Storage.
- Publish the application online using Netlify.
- Manage project files using GitHub.

## 3. Key Features

### Dashboard
- Total budget overview.
- Total expenses overview.
- Remaining balance.
- Visual budget progress indicator.

### Expense Management
- Add new expenses.
- Choose expense categories.
- Delete expenses.
- Search expenses by name.
- Filter expenses by category.
- Export expense records to CSV.

### Data Storage
- Save budget information.
- Store expenses in browser Local Storage.
- Keep saved records after refreshing the browser.

### Responsive Design
- Professional dashboard layout.
- Modern colors and typography.
- Desktop, tablet, and mobile-friendly design.

## 8. Website Deployment Using Netlify

SpendWise is designed to be hosted as a static website using Netlify.

Deployment process:

1. Sign in to Netlify.
2. Select Add new project.
3. Choose Import an existing project.
4. Connect your GitHub account.
5. Select the `spendwise-week7` repository.
6. Leave the build command empty.
7. Set the publish directory to the project root.
8. Click Deploy.

### Live Website

**Netlify URL:** ADD_YOUR_NETLIFY_URL_HERE

Replace this placeholder with the actual published website URL after successful deployment.

## 9. Automatic Deployment

Netlify can automatically publish website updates whenever changes are pushed to the connected GitHub repository.

To verify automatic deployment:

1. Make a small change to the website.
2. Save the updated file.
3. Commit and push the changes to GitHub.
4. Check the deployment status on Netlify.
5. Open the live website and confirm the update.
